# Code of Conduct

Be direct about the work and considerate toward the person doing it.

In this project:

- critique ideas, code, and evidence—not identity or ability;
- assume mistakes are fixable and ask before assigning intent;
- do not harass, threaten, discriminate, sexualise, or publish another person's
  private information;
- do not include secrets or private project data in examples; and
- respect a clear request to stop an unwanted interaction.

These expectations apply in issues, pull requests, reviews, discussions, and
other spaces representing the project.

The maintainer may edit or remove contributions, lock threads, or temporarily or
permanently exclude participants whose behaviour makes collaboration unsafe or
unproductive. When practical, moderation will explain which behaviour crossed
the line and what would need to change.

Report conduct concerns privately to
[`hello@gtlr.studio`](mailto:hello@gtlr.studio). Include links or screenshots
only when they can be shared safely; do not forward unrelated private project
data. Good-faith reports and participants in an investigation must not be
retaliated against.
